📄 Advanced SSH Log Analysis

SOC / DFIR Level — Linux Security Investigation Toolkit

📂 Log Sources

/var/log/auth.log
/var/log/secure
/var/log/syslog
journalctl -u ssh

🔍 Deep Log Extraction (journalctl)

# All SSH logs
journalctl -u ssh

# Last boot SSH logs
journalctl -u ssh -b

# Time range
journalctl -u ssh --since "2026-04-14 10:00" --until "2026-04-14 12:00"

# Failed logins only
journalctl -u ssh | grep "Failed password"

🧠 Advanced Brute Force Detection

IP + Username Correlation

grep "Failed password" /var/log/auth.log | awk '{print $(NF-3), $9}' | sort | uniq -c | sort -nr

Password Spray Detection (many users, same IP)

grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | awk '$1 > 10'

Targeted Attack (single user, many IPs)

grep "Failed password for root" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr

🕵️ Attack Pattern Analysis

Detect SSH Scanning Tools (Hydra/Ncrack)

grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr | head
👉 Indicators:
• High frequency attempts
• Sequential usernames
• Same IP hitting many accounts

👤 User Behavior Analysis

Login Timeline per User

grep "Accepted" /var/log/auth.log | awk '{print $1,$2,$3,$9}'

Rare / New User Login

grep "Accepted" /var/log/auth.log | awk '{print $9}' | sort | uniq -c | sort -n

🌐 Geo / External IP Detection

Extract External IPs

grep "Accepted" /var/log/auth.log | awk '{print $(NF-3)}' | grep -vE "^192\.168|^10\.|^172\." | sort | uniq

🚨 Suspicious Login Detection

Midnight / Off-hours Login

grep "Accepted" /var/log/auth.log | awk '$3 ~ /00|01|02|03|04/'

First-time Login IP

grep "Accepted" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | awk '$1==1'

🔑 Privilege Escalation Detection

sudo usage after SSH login

grep "sudo" /var/log/auth.log

SSH → Root escalation chain

grep -E "Accepted|sudo" /var/log/auth.log

🔁 Session Correlation

Track full session (open → close)

grep -E "session opened|session closed" /var/log/auth.log

📡 Lateral Movement Detection

Same user from multiple IPs

grep "Accepted" /var/log/auth.log | awk '{print $9,$(NF-3)}' | sort | uniq -c

🧪 Persistence Detection

SSH Key Injection

grep "authorized_keys" /var/log/auth.log

New SSH key added

grep "Accepted publickey" /var/log/auth.log

🔥 Data Exfiltration Indicators

SCP / SFTP usage

grep -E "scp|sftp" /var/log/auth.log

🔴 Real-Time Detection Pipeline

tail -f /var/log/auth.log | grep --line-buffered -E "Failed password|Accepted|Invalid user"

🤖 Advanced Bash Analyzer Script

#!/bin/bash

LOG="/var/log/auth.log"

echo "===== ADVANCED SSH ANALYSIS ====="

echo "[+] Failed Attempts:"
grep "Failed password" $LOG | wc -l

echo "[+] Success Logins:"
grep "Accepted" $LOG | wc -l

echo "[+] Top Attackers:"
grep "Failed password" $LOG | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr | head

echo "[+] Targeted Users:"
grep "Failed password" $LOG | awk '{print $9}' | sort | uniq -c | sort -nr | head

echo "[+] Invalid Users:"
grep "Invalid user" $LOG | awk '{print $8}' | sort | uniq -c | sort -nr

echo "[+] Possible Brute Force (>10 attempts):"
grep "Failed password" $LOG | awk '{print $(NF-3)}' | sort | uniq -c | awk '$1>10'

echo "[+] Unique Successful IPs:"
grep "Accepted" $LOG | awk '{print $(NF-3)}' | sort | uniq
